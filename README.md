# AI Security Sandbox

AI Security Sandbox is a project for testing and evaluating the security behaviour of AI models in a controlled environment. The basic idea is to provide different AI models with predefined test cases, collect their responses, evaluate those responses using defined criteria, and store the results so that the behaviour of different models can be compared.

The project will initially focus on building a simple working system rather than trying to create a complete security platform from the beginning. The first version will connect to selected AI models or APIs, run a set of predefined tests, record the responses, and provide basic evaluation and comparison of the results.

As development continues, the system can be expanded with more testing methods, automated evaluation, better result analysis, additional models, and a more advanced sandbox environment.

## Current Goal

Build the first functional version of the platform:

**Test → Collect → Evaluate → Store → Compare**

This repository contains the source code, documentation, testing modules, and other components required to develop the project.

## Project Status

🚧 **Early Development**

The project is currently being developed as a collaborative learning and research-oriented project. The initial implementation will be kept simple so that the team can understand the complete workflow before moving toward more advanced features.
